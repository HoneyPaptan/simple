# Keyboard shortcuts

Physical keyboard only unless noted.

## Composer (chat and home)

| Keys | Action |
|------|--------|
| Enter | Send |
| Shift+Enter | New line |
| Esc | Close suggestions first, then close composer |

On screen keyboards, Enter still inserts a new line.

## Home

| Keys | Action |
|------|--------|
| Ctrl+K | Open search |
| Ctrl+N | Open new agent sheet |

## Chat

| Keys | Action |
|------|--------|
| Ctrl+[ | Previous agent in list order |
| Ctrl+] | Next agent in list order |

Order matches swipe: waiting agents first, then recents by `updated`.

## Terminal view

All keys go to the remote PTY, so Ctrl+[ is Esc there and agent switching is chat only, including Ctrl, Alt, arrows, Tab, Esc, Home, End, Page Up, Page Down, and F1 through F12, using the same escape sequences as Termux `KeyHandler`.
